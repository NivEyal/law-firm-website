# Law Firm – Lawyer & Law Firm Website Template

A clean, responsive HTML5 website template designed for law firms and legal professionals.

## 🗂 Project Structure

```
law-firm-free/
├── index.html          # Main HTML file
└── assets/
    ├── css/            # Stylesheets (Bootstrap, custom styles, animations)
    ├── js/             # JavaScript files (jQuery, Bootstrap, Slick slider)
    ├── images/         # Images (slider, team, blog, etc.)
    └── fonts/          # Icon fonts (LineIcons)
```

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/law-firm-website.git
   ```

2. Open `index.html` in your browser — no build step required.

## ✏️ Customisation

- **Content** – Edit `index.html` directly.
- **Styles** – Modify `assets/css/style.css` for custom colours and layout tweaks.
- **Images** – Replace files in `assets/images/` with your own (keep the same filenames, or update the `src` attributes in `index.html`).
- **JavaScript** – Custom behaviour lives in `assets/js/main.js`.

## 📦 Dependencies (bundled)

| Library | Version | Purpose |
|---|---|---|
| jQuery | 1.12.4 | DOM manipulation |
| Bootstrap | 4 | Responsive grid & components |
| Slick Slider | – | Hero/testimonial carousel |
| Animate.css | – | Scroll animations |
| LineIcons | – | Icon font |
| Magnific Popup | – | Lightbox |

All dependencies are included locally — no internet connection required to run the template.

## 🌐 Deployment

This is a static site. You can host it on:

- **GitHub Pages** – push to a `gh-pages` branch or enable Pages on `main`.
- **Netlify / Vercel** – drag-and-drop the folder, or connect the repo.
- **Any static host** – upload the files via FTP.
